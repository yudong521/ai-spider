# 🕷️ 智能爬虫 Agent

基于大语言模型（LLM）的智能网页爬取与信息提取系统。只需描述你的需求，Agent 会自动规划爬取路径、提取关键信息并整理输出。

## ✨ 功能特性

### 🎯 智能爬取

- **自然语言任务定义**：用简单的描述告诉 Agent 你想获取什么信息
- **自动路径规划**：从入口 URL 出发，智能探索相关链接
- **内容智能提取**：自动过滤无关信息，只保留与任务相关的内容
- **结构化输出**：将收集的信息整理成易读的格式

### 📊 任务管理

- **任务创建与管理**：支持创建、编辑、删除爬取任务
- **定时执行**：支持间隔执行、Cron 表达式、一次性定时三种模式
- **实时日志**：通过 SSE 实时推送执行过程
- **Token 统计**：详细记录每次执行的 Token 消耗

### 🎨 现代化界面

- **深色主题**：精心设计的深色 UI
- **实时监控**：查看 Agent 的每一步思考和行动
- **Markdown 渲染**：优雅展示爬取结果
- **一键导出**：支持复制和导出结果

## 🚀 项目亮点

### 1. 双 Agent 协作架构

本项目采用创新的**双 Agent 架构**，将爬取任务分解为两个专业化的 Agent：

```
┌─────────────────────────────────────────────────────────────┐
│                        用户任务                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Main Agent (主 Agent)                     │
│  • 理解用户需求                                               │
│  • 规划爬取策略                                               │
│  • 决定访问哪些页面                                           │
│  • 整合信息并输出最终结果                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              │ 调用 crawl_url 工具
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  Extract Agent (提取 Agent)                  │
│  • 接收原始网页内容（可能很长）                                 │
│  • 根据用户任务提取相关信息                                    │
│  • 识别值得进一步探索的链接                                    │
│  • 返回精简的结构化内容                                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              │ 返回提取后的精简内容
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Main Agent 继续规划                       │
└─────────────────────────────────────────────────────────────┘
```

### 2. 有效缓解上下文腐烂

传统单 Agent 方案的问题：
- 每次爬取都会将完整的网页内容加入上下文
- 随着爬取页面增多，上下文中积累大量无关信息
- Agent 容易"迷失"，忘记原始任务目标

**我们的解决方案：**
- Extract Agent 作为"信息过滤器"，只提取与任务相关的内容
- Main Agent 的上下文中只包含精简后的关键信息
- 保持上下文清晰聚焦，Agent 始终记得任务目标

### 3. 显著节省 Token 消耗

避免历史网页内容在主Agent中不断堆积，只提取保留有用信息


### 4. 灵活的模型选择

支持为 Main Agent 和 Extract Agent 分别配置不同的模型：

- **Main Agent**：推荐使用推理能力强的模型（如 qwen3-max）
- **Extract Agent**：可使用性价比更高的模型（如 qwen3-plus）

## 📦 技术栈

### 后端

- **FastAPI** - 高性能异步 Web 框架
- **SQLAlchemy** - ORM 数据库操作
- **LangChain** - LLM 应用开发框架
- **Crawl4AI** - 智能网页爬取库
- **APScheduler** - 定时任务调度

### 前端

- **Vue 3** - 渐进式 JavaScript 框架
- **Element Plus** - Vue 3 UI 组件库
- **Pinia** - Vue 状态管理
- **Vite** - 下一代前端构建工具

## 🛠️ 快速开始

### 环境要求

- Python 3.11+
- Node.js 18+
- 支持的 LLM API Key（阿里千问、智谱 AI）

### 后端启动

```bash
# 进入后端目录
cd backend

# 安装依赖（推荐使用 uv）
uv sync
# 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 前端启动

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:3000 即可使用。

### 配置 API Key

1. 打开设置页面
2. 填入你的 LLM API Key（支持阿里千问、智谱 AI）
3. 点击测试连接确认配置正确

## 📖 使用示例

### 示例 1：获取技术博客最新文章

```
任务描述：获取该博客最近发布的 5 篇文章的标题、发布时间和摘要
入口 URL：https://example-tech-blog.com
```

### 示例 2：收集产品信息

```
任务描述：收集该网站所有产品的名称、价格和规格参数
入口 URL：https://example-shop.com/products
```

### 示例 3：监控新闻动态

```
任务描述：获取今天发布的所有关于 AI 的新闻标题和链接
入口 URL：https://example-news.com/tech
定时执行：每天 9:00
```

## ⚠️ 局限性

### 仅支持开放网站

本系统**仅适用于无需认证、公开访问的网站**：

- ✅ 公开的博客、新闻网站
- ✅ 无需登录的产品页面
- ✅ 开放的 API 文档
- ❌ 需要登录的网站
- ❌ 需要 API Key 认证的接口
- ❌ 有反爬机制的网站
